# rcc

Implementing [Writing a C Compiler by Nora Sandler](https://nostarch.com/writing-c-compiler) in Rust.

Currently in progress.

## Requirements

Similar to the book is only supported on Linux and Mac.

Windows is not supported directly, you have to use WSL.

- `python3` `>=3.8`
- `gcc, gdb` for Linux
- `clang` for Mac
- `rustc`
- [just](https://github.com/casey/just) for task runner

The commands are written to be OS agnostic, but have only been tested on MacOS.
